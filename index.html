Mindshort

Publish Mindshort videos to TikTok from one simple workspace.

Mindshort is a content management and publishing tool operated by Maxime Mandeville in Longueuil, Quebec, Canada. It lets the signed in user connect a TikTok account, choose a finished video, write its caption, and publish the video directly to that TikTok profile.

See how it works Read the Privacy Policy

What this tool does

Mindshort produces short French language mindset videos for TikTok, including content related to its program Le Déclic. This tool exists for one job: getting those finished videos onto the company's TikTok profiles in a controlled way, with the right account, the right caption and the account holder's authorization at every step.

Account confirmation

After signing in with TikTok, the tool shows the connected account's display name, username and avatar, so the user can confirm the right account is connected before anything is posted.

Video selection

The user chooses a finished video file from their own library. The tool does not browse, download or reuse anyone else's content.

Caption writing

The user writes or edits the caption that will appear with the video on TikTok. The published text is always the text the user approved.

Direct publishing

With the user's authorization, the tool uploads the selected video to TikTok and publishes it to the connected TikTok profile. Nothing is posted without the user's action.

How it works

Four steps, start to finish. The flow uses TikTok Login Kit for sign in and the TikTok Content Posting API for the upload and the post.

1

Sign in with TikTok

The user signs in with TikTok and grants the permissions the tool requests. Sign in is handled by TikTok itself; the tool never sees the user's password.

2

Confirm the account

The tool displays the connected account's basic profile information, so the user can verify exactly which TikTok profile will receive the post.

3

Prepare the post

The user selects a finished video file and writes the caption that will be published with it.

4

Publish

The tool uploads the video to TikTok and publishes it to the connected profile. The user can then view the live post in TikTok.

TikTok connection and permissions

The tool connects to TikTok through TikTok for Developers and only requests the permissions it needs to publish content the user has chosen. Here is what each permission is used for, in plain language.

  • Basic account information (user.info.basic) Identifies the account that signed in, so the tool knows which profile is connected.
  • Profile information (user.info.profile) Shows the display name, avatar and public profile details inside the tool, so the user can confirm the account before posting.
  • Video upload (video.upload) Sends the video file the user selected to TikTok, ready to be posted.
  • Video publishing (video.publish) Publishes that uploaded video, with the user's caption, to the user's own TikTok profile.

The account holder can review or revoke the tool's access at any time from their TikTok settings. Full details about the information the tool accesses and how it is handled are in the Privacy Policy, and the rules for using the tool are in the Terms of Use.

Who this tool is for

Mindshort is built for the Mindshort business itself: a small company operated by Maxime Mandeville in Longueuil, Quebec, Canada, that creates French language mindset content for TikTok. The tool is used to publish the company's own finished videos to the company's own TikTok accounts. It is not a general purpose social media service, it is not offered to the public as a posting platform, and accounts are connected only with the account holder's authorization.

About Mindshort

Mindshort creates short French language videos about mindset, confidence and taking action, published on TikTok. Mindshort also offers Le Déclic, a 14 day program built around one short audio and one short chapter per day, with practical exercises. This developer application and this website exist so the Mindshort team can publish that content to TikTok with TikTok's official tools.
